# Human Eye — Public Browser Demo

Interactive 3D and WebXR demonstration of myopia, hyperopia, glaucoma and cataract.

Desktop/mobile: drag to orbit, scroll to zoom, choose a condition and apply correction or treatment. Quest Browser: open the HTTPS demo and select Enter VR.

Educational simulation. Eye anatomy and vision effects are illustrative. Physical Quest 2 and Quest 3S testing remains pending.
